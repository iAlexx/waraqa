## Policy

1. Never overwrite, delete, rename, or move screenshots from a previous round.
2. Every capture run writes only into `revisions/round-XX-short-description/`.
3. Do not write new screenshots into the Phase 3 root.
4. Copy into `approved/` only after explicit owner approval of that exact revision.
5. Use **fictional data only** in Admin captures — never real personal data or invented official claims presented as verified.
6. Phase 2 QA under `docs/qa/phase-2/` remains **untouched**.
7. Do not commit passwords, `.local-credentials`, or session tokens.
