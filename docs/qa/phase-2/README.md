# Phase 2 — Visual QA

## Structure

```text
docs/qa/phase-2/
  README.md          ← this index
  revisions/         ← one folder per visual revision (never overwrite)
  approved/          ← owner-approved revision copies
  *.png              ← legacy pre-policy captures (preserved; do not delete Round archives)
```

## Policy (from Round 04 onward)

1. Never overwrite, delete, rename, or move screenshots from a previous round.
2. Every capture run writes only into `revisions/round-XX-short-description/`.
3. Do not write new screenshots into the Phase 2 root.
4. Copy into `approved/` only after explicit owner approval of that exact revision.
5. Each revision folder includes `README.md`, `CHANGES.md`, and `comparison-contact-sheet.png`.
6. Paths reported to the owner must include the full revision folder.
